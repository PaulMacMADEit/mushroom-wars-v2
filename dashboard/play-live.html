Play live vs a trained agent

You play P1 by clicking buildings; the trained agent plays P2. Pick the model to face from a dropdown in the top-left — first switch downloads weights from Supabase (~1–3s), subsequent switches use the cached file. Play queues batch AI-vs-AI matches; this page is local human-vs-AI.
1. Start the local server
python scripts/play_live.py
Run from the mushroom-wars-v2/ repo root. Uses CPU so it won't steal GPU time from the training loop.
2. Open it
Open localhost:8765 →
Opens in a new tab. If you see "connection refused", go back to step 1.
Why local-only: live click-to-click play needs the Python sim and a torch model loader running together — neither exists in a static GitHub Pages site. The server runs the sim, the browser paints it.
