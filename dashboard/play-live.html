Local play server isn't running

Live click-to-click play needs the Python sim + torch model loader running on this machine. The Mac launchd service should auto-start it, but if it's not up, run it manually:
1. Start the local server
python scripts/play_live.py
Run from the mushroom-wars-v2/ repo root. Uses CPU so it won't steal GPU time from the training loop.
2. Reload this page
The page will auto-detect the server on localhost:8765 and embed the game here.
Why not pure browser: the v13 model is only ~7.5 MB (trivial in the browser), but the sim engine — building physics, capture rules, fighter motion — is ~1,500 lines of Python validated against a numpy reference. Porting it to JS without parity drift is days of work, vs the localhost setup which runs the canonical sim unchanged.
